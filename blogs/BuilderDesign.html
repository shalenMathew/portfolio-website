A Quick Guide into Builder Design Pattern in Android

Published: 27-05-2026

This quick guide to the Builder Design Pattern is perfect whether you're looking for a quick revision or trying to understand the concept from scratch.

The Builder Pattern is a creational design pattern used to construct complex objects step by step. It's especially useful when an object has many optional fields or when you want to make object creation more readable and manageable.

If a class has many parameters, instead of adding all of them to the constructor and creating a telescoping constructor, the Builder Pattern provides a better approach by letting you separate optional parameters cleanly.

Let's understand this with a clear example using a Person class. In this class, there are fields like firstName, lastName, middleName, age, phoneNo, and address. Among these, firstName, lastName, and age are the only mandatory fields.

The Problem: Without the Builder Pattern

Without the Builder pattern, your implementation can turn into telescoping constructors like this:

class Person(val firstName: String, val lastName: String, val age: Int) {
    constructor(firstName: String, lastName: String, age: Int, middleName: String) : this(firstName, lastName, age)
    constructor(firstName: String, lastName: String, age: Int, middleName: String, phoneNo: String) : this(firstName, lastName, age, middleName)
    constructor(firstName: String, lastName: String, age: Int, middleName: String, phoneNo: String, address: String) : this(firstName, lastName, age, middleName, phoneNo)
}

fun main() {
    val person1 = Person("John", "Doe", 30)
    val person2 = Person("Alice", "Smith", 25, "Marie")
    val person3 = Person("Bob", "Johnson", 40, "David", "123-456-7890")
    val person4 = Person("Charlie", "Brown", 35, "Robert", "987-654-3210", "1234 Elm St")
}

A Better Approach: Implementing the Builder Pattern

Here is how we can structure and build this class using the Builder Pattern more cleanly:

data class Person(
    val name: String?,
    val lastName: String?,
    val age: Int?,
    val middleName: String? = null,
    val phoneNo: Int? = null,
    val address: String? = null
) {
    class PersonBuilder(val name: String, val lastName: String, val age: Int) {
        var middleName: String? = null
        var phoneNo: Int? = null
        var address: String? = null

        fun middleName(middleName: String?) = apply {
            this.middleName = middleName
        }

        fun phoneNo(phoneNo: Int?) = apply {
            this.phoneNo = phoneNo
        }

        fun address(address: String?) = apply {
            this.address = address
        }

        fun build(): Person {
            return Person(name, lastName, age, middleName, phoneNo, address)
        }
    }
}

fun main() {
    val p1 = Person.PersonBuilder(name = "Shalen", lastName = "Mathew", age = 22)
        .phoneNo(911)
        .address("Bangalore")
        .build()
}

What's happening in the code?

The Person class has fields like name, lastName, age, middleName, phoneNo, and address. Some of these are optional, like middleName, phoneNo, and address.

Inside the Person class, there's a nested PersonBuilder class. This builder helps you create a Person object step by step. The mandatory fields are passed into the builder constructor up front.

How it works

  • You create a PersonBuilder instance by passing the required fields: name, lastName, and age.
  • You can then add optional values using chainable methods like .middleName(), .phoneNo(), and .address().
  • Each setter uses Kotlin's apply so it returns the builder itself and keeps the chaining clean.
  • Finally, calling .build() returns the finished Person object.

The Kotlin Way: An Optimized Alternative

While the previous code follows a traditional Java-style builder, Kotlin gives us a more direct option.

In Kotlin, a data class with default values can often give you builder-like flexibility without creating an explicit builder class.

data class Person(
    val name: String,
    val lastName: String,
    val age: Int,
    val middleName: String? = null,
    val phoneNo: Int? = null,
    val address: String? = null
)

fun main() {
    val person = Person(
        name = "Shalen",
        lastName = "Mathew",
        age = 22,
        phoneNo = 911,
        address = "Bangalore"
    )

    println(person)
}

Explanation

  • The data class has required parameters like name, lastName, and age.
  • The optional parameters use default values, so you can omit them safely when creating a Person object.
